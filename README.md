# Incident Tracker 🛡️

A lightweight, secure web-based incident tracking system designed to help IT departments and cybersecurity teams report, track, and manage incidents in real time.

## 🚀 Features
- Submit incident reports with a title and description
- View all active and past incidents
- Mark incidents as closed
- Client-side form validation
- Simple, responsive UI built in React

## 💡 Use Case
This tool simulates a basic helpdesk or security incident tracker. It’s perfect for learning about:
- Frontend development (React)
- State management
- IT operations workflows
- Cybersecurity reporting basics

## 🛠 Tech Stack
- **Frontend:** React, Tailwind CSS (optional)
- **Backend:** None (this version is frontend-only)
- **Hosting:** Local development or deploy via Vercel/Netlify
